UnTangled package feed

A modern web interface for OpenWRT — installable with your router's own package manager.

Add this feed once, then UnTangled installs and upgrades like any other OpenWRT package. All packages and the feed index are cryptographically signed; your router verifies them automatically.

Not sure which you have? Run cat /etc/openwrt_release on the router. A DISTRIB_RELEASE like 24.10.x is stable; SNAPSHOT is snapshot.

Stable OpenWRT (23.05 / 24.10) — opkg

Run these on the router (SSH, or LuCI → System → Custom Commands):

# 1. Trust the UnTangled signing key (one time)
wget -O /tmp/untangled.pub https://bidhata.github.io/untangled/keys/untangled.pub
opkg-key add /tmp/untangled.pub

# 2. Add the feed (one time)
echo 'src/gz untangled https://bidhata.github.io/untangled/stable' >> /etc/opkg/customfeeds.conf

# 3. Install
opkg update
opkg install untangled-full      # or: untangled (minimal)  /  untangled-mesh (Mesh Wi-Fi)

Later upgrades: opkg update && opkg upgrade untangled untangled-full untangled-mesh.

OpenWRT snapshot — apk

# 1. Trust the UnTangled signing key (one time)
wget -O /etc/apk/keys/untangled.pem https://bidhata.github.io/untangled/keys/untangled.pem

# 2. Add the feed (one time)
echo 'https://bidhata.github.io/untangled/snapshot/packages.adb' > /etc/apk/repositories.d/untangled.list

# 3. Install
apk update
apk add untangled-full           # or: untangled  /  untangled-mesh

Later upgrades: apk update && apk upgrade. Because the key is trusted, no --allow-untrusted is ever needed.

The feed is served over HTTPS. OpenWRT needs TLS support for that — present on practically every modern image (libustream-mbedtls or -wolfssl plus ca-bundle). If wget/opkg update complain about SSL, install ca-bundle first from the official feed.

After installing

Open http://<router-ip>/untangled/ and log in with your router's admin account. UnTangled runs alongside LuCI — it never replaces or alters it. Full setup notes: openwrt/README.md.
